# Setup en 30 segundos

> Versión en inglés disponible en la barra lateral en **Guides > Setup**.

## 1. Instalación

```bash
pnpm add @raulrod/ui @raulrod/tokens @raulrod/icons
```

## 2. Cargar los estilos una vez

Añade estas dos importaciones en la raíz de tu app:

```tsx
// main.tsx o App.tsx
import "@raulrod/tokens/styles.css";
import "@raulrod/ui/styles.css";
```

## 3. Usar un componente

```tsx
import { Button } from "@raulrod/ui";

export default function App() {
  return <Button>Empezar</Button>;
}
```

## 4. Providers opcionales

La mayoría de componentes funcionan sin provider. Envuelve tu app con
`ToastProvider` solo si usas toasts:

```tsx
import { ToastProvider } from "@raulrod/ui";

<ToastProvider>
  <App />
</ToastProvider>;
```

## 5. Cambiar de tema

Añade `data-theme` a `<html>`:

```html
<html data-theme="dark"></html>
```

O no lo configures para que siga el `prefers-color-scheme` del usuario.
