# RaulRod UI

`@raulrod/ui` is a small, strict-TypeScript React component library built around
design tokens, semantic CSS variables, and explicit contracts.

It is intended for personal projects and for demonstrating how a real design
system is organized: tokens → components → documentation → package → consumer
app.

## What you get

- **Design tokens** in `@raulrod/tokens` (primitive + semantic + component
  layers).
- **CSS-only styling** via custom properties (`--rr-*`), no CSS-in-JS runtime.
- **Accessible primitives** and compound components (Dialog, Select, Tabs, …).
- **Tree-shakeable icons** through `@raulrod/icons` (re-export of
  `lucide-react`).

## Quick start

Install the packages and load the CSS once at the root of your app:

```tsx
import "@raulrod/tokens/styles.css";
import "@raulrod/ui/styles.css";

import { Button } from "@raulrod/ui";

export default function App() {
  return <Button>Get started</Button>;
}
```
