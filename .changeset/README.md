# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, and it includes a `config.json` file.

## Useful commands

- `pnpm changeset` — create a new changeset for a package.
- `pnpm version-packages` — bump versions and update changelogs from pending changesets.
- `pnpm release` — build and publish packages (intended for CI only).

See [ADR-006](../docs/decisions/006-release-strategy.md) for the release strategy.
